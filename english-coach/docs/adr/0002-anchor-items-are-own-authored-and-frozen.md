# 锚题自制并冻结，不宣称与外部考试分数等价

我们要在每次测评里混入几道固定题目，用来观察整套测评的难度有没有随时间漂移。调研结论是：**不存在任何可以随插件一起分发的、按欧洲语言共同参考框架分级的四选一题库**。剑桥与雅思的条款明确禁止抓取内容建库并只允许个人非商业使用；ETS 可以授权，价格是每题 225–450 美元；少数开放的 CEFR-J 样例题是图片选择与填空格式，改造成四选一即落入二次创作的授权灰区。

因此我们自制 5 道锚题：原创情境，难度从 CEFR-J 词表与语法表反查锚定（那份授权允许在标注出处的前提下用于研究及商业用途），选项按验证过的题目编写规范构造（正确项 + 母语干扰 + 过度泛化 + 搭配错误），经两人盲测后**冻结**——记录 SHA-256，永不修改，只能退役。

这带来三个必须接受的后果：

1. **不能打包词表本身**。词表有汇编版权，只能打包我们这几道锚题实际用到的那几个词的级别查询结果。CEFR-J 要求在 NOTICE 里给出指定引用字符串。
2. **不能声称分数等值**。5 道锚题足以监控尺子有没有漂，但等值理论要求 15–20 道。所以进度页上只能说"水平趋势"，不能说"精确可比分数"。这一条是刻意写进文档的，防止以后有人把它当成等值分数来用。
3. **锚题会过期**。冻结意味着它永远不变，也意味着它的难度校准永远不会更好——前约 50 次测评的锚题成绩只记不判，用来积累响应数据。

相关的第二道墙：Octanove 的 C1/C2 词表是 CC BY-SA，具有传染性。如果要用，只能作为单独一个明确标注的文件引入，绝不能与其他数据揉在一起。
