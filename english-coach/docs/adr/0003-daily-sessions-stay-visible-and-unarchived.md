# 每日生成任务使用可见且不归档的会话

DSH 明确拒绝把定时投递送进不可见的会话（`subagent_session` 投递永远无法到达），也没有"后台隐身模式"。所以每天那次自动生成，必然会在侧边栏留下一个会话。

我们选择：**每天新建一个会话，跑完不归档**，并且把它创建在数据目录下，让这些会话在侧边栏聚成独立的一组，不与代码库混在一起。

选不归档而不是归档，理由是**可追溯**：某天的课程如果让你觉得"这篇怎么这么难"或"这个表达解释得不对"，你可以回到那天的会话，看到它当时搜了什么、为什么选了这篇、拒绝了哪些来源。归档虽然让侧边栏干净，但也让这套系统变成一个黑盒——而这是唯一能审计它判断的地方。

代价是侧边栏会持续增长，而且每个会话都是完整的一轮模型调用（含工具调用），历史无法自动压缩。这个代价是可接受的：一天一条，一年 365 条，都在一个独立的组里。如果将来觉得碍事，归档是一个随时可做的动作，不需要改 schema。
