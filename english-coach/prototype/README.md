# 英语教练 · 独立布局原型

## 打开

双击本目录的 [index.html](./index.html)，直接以 `file://` 打开。不需要构建、安装依赖或启动服务器。

底部浮条切换 A / B / C，也可以按 `←` / `→`；`◐` 切换明暗主题。支持通过 `?variant=A`、`?variant=B` 或 `?variant=C` 直接选择布局。部分浏览器不允许本地文件更新地址参数，此时浮条仍可切换。

## 三种布局

- **A · 学习日报**：单栏阅读，从今日课程、到期词汇一直看到目标与进度；词汇在浮层中练习。
- **B · 工作台**：今天 / 单词 / 计划 / 进度四个标签页，双栏展示课程、复习卡与词库。
- **C · 专注模式**：词汇 → 听力 → 测验 → 排序，一次展示一个任务；「看全部」显示总览。

## 合成数据与边界

所有课程、英文句子、词汇练习、对话、会话标题、日期和进度都是纯合成示例，不包含个人学习数据、来源原文摘录或真实课程截图。示例固定包含 10 个词（4 个今天到期）与 5 个学习项（2 个已完成）。

这不是正式插件，只用于比较布局。交互状态仅保存在当前页面内存中，刷新后重置；不发出真实学习请求，不保存学习记录，不访问真实学习数据。播放、全文及设置等按钮仅作界面占位，不会播放音频或调用后端。
