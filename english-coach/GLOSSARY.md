# 英语教练

一个装在 DeepSeek Harness 里的英语学习插件：判断学习者的水平，维护一份学习路线，每天准备一课，并让复习随时可以在碎片时间里点几下完成。

这份词汇表只收录这个上下文里特有的概念。通用的编程概念（超时、错误类型、工具函数）不在这里。

## 语言

### 学习者

**画像 / Profile**：
关于学习者本人的、相对静态且可编辑的事实：职业方向、兴趣主题、每天可用时长、目标档位。不含任何成绩或答题记录。
_Avoid_: 用户资料、persona、人设

**水平估计 / LevelEstimate**：
对"当前能力处于哪一档"的判断，带时间戳与置信度，随测评更新，也可能因为退步而下降。
_Avoid_: 等级、分数、评级

**档位 / Band**：
面向学习者呈现水平的六个中文名称之一：入门 / 初级 / 中级 / 中高级 / 高级 / 精通。内部对应一张更细的量表，但那套量表的名称不出现在界面上。
_Avoid_: CEFR 等级、A1/B2、英语级别

**档位参照 / BandReference**：
对档位的一句描述性对照，例如"大致相当于四级水平"。它用于帮助学习者自评是否测得准，不构成任何形式的分数等价。
_Avoid_: 分数换算、等值、对应分数

**水平曲线 / LevelCurve**：
历次水平估计按时间连成的线，是进度页的主视觉。
_Avoid_: 等级图、成长曲线

### 学习路线

**大纲 / Syllabus**：
固化的学习路线：阶段划分与本阶段目标。不含具体日期，不因单日表现改动。
_Avoid_: 课程表、计划表、学习计划

**课程 / Lesson**：
某一天的具体学习内容，包含阅读、听力、表达、题目与可选的排序。它有四种状态：草稿、进行中、已完成、已过期。
_Avoid_: 每日任务、学习包、课件

**学习项 / StudyItem**：
一堂课里最小的可完成单元：一段阅读、一段听力、一组表达、一组题目、一次排序。
_Avoid_: 任务、章节、section

**草稿 / Draft**：
已生成、但学习者尚未开始的课程。把一个"已生成"的课程说成"已学"是这个领域最常见的错误。
_Avoid_: 今日课程（在未开始时不要这样称呼）

### 复习

**复习项 / ReviewItem**：
进入复习队列的一个单词或一整块表达。整块表达优先于孤立的单词。
_Avoid_: 单词卡、词条、生词

**复习队列 / ReviewQueue**：
所有复习项按到期时间排成的队列，由答题记录驱动，独立于课程存在。
_Avoid_: 背单词计划、词库、生词本

**盒子 / Box**：
复习项在队列中所处的阶段。答对推进一盒，答错退回第一盒。
_Avoid_: 等级、level、轮次

**掌握 / Mastered**：
复习项在 1 天、7 天、30 天三个间隔上各答对一次之后的状态。掌握之后仍会被抽检。
_Avoid_: 记住、学会、熟练

### 测评

**锚题 / AnchorItem**：
每次测评都会出现的固定题目，用于观察整套测评的难度是否发生漂移。冻结后不可修改，只能退役。
_Avoid_: 基准题、校准题、样题

**测评 / Assessment**：
一组按难度自适应的选择题，产出一个新的水平估计。它不是考试，不给证书，也不宣称与他人可比。
_Avoid_: 考试、测试卷、评级

### 界面与素材

**碎片卡 / FlashCard**：
悬浮层里一次只显示一张的短内容单元，覆盖到期复习和当天的短学习项。
_Avoid_: 卡片、单词卡、闪卡

**素材来源 / Source**：
一份被采纳进课程的阅读或听力材料，必须带可访问的原始链接、抓取时间与许可说明。
_Avoid_: 资源、链接、参考

**音频来源 / AudioProvider**：
把一段英文文本变成可听声音的途径。默认使用浏览器自带的语音合成，可替换为素材原始音频或外部语音服务。
_Avoid_: 朗读器、TTS、配音
