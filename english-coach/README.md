# 英语教练 · English Coach

> A DeepSeek Harness plugin that prepares one English lesson a day, keeps a spaced-repetition queue, and stays out of the way. Chinese UI; English only in the learning material. No API key, local-first, MIT.

**英语教练**是装在 DeepSeek Harness 里的英语学习插件。它替你做那件每天要花二三十分钟的杂活：判断水平、找难度合适的材料、抠出值得记的表达、排复习。你只负责学。

## 它是什么

- **今天学什么** — 每天由 Agent 按你的画像和近期工作方向找素材、加工成一课，先存草稿，你点开始才算开始。
- **词** — 所有来源的到期旧词优先，其次是已加入但未首次作答的新词；当前词库的新词优先。今日、单词页和悬浮层共用当前轮次、题号、作答反馈与成绩，切走再返回不会重开本轮；切库下一批生效。`1`–`4` 直接选，答完给释义和讲解。
- **碎片时间** — 右下角一颗药丸，显示待复习数，点开就能答：词、四个释义、点一个，答完给讲解；按住可以拖到别处，位置记在本机。
- **想多学** — 统一点「继续学习」：先取到期旧词和已加入新词；已选词库时使用该库的内置基础练习，未选词库且没有可学候选时按画像由 Agent 准备新词。每批默认 10，可调 3–30，不是每日上限。
- **听英文** — 阅读、听力、单词和表达支持手动朗读；文章可暂停、继续、重听和拖动文本进度，跨重开静默恢复书签。阅读与听力的逐段中文译文默认收起，点击对应段落下的「译文」才展开。
- **有没有进步** — 已掌握数量、连续天数、水平曲线、薄弱项。

「今日」把课程放在左边，单词学习放在右栏；「单词」以本轮学习为主，查词与设置按需打开。

![今日](docs/panel-today.png)

## 环境要求

- DeepSeek Harness **桌面版 `0.2.1-rc.3`**：当前 `engines.dsh` 仅声明这个精确版本，不推断其他版本兼容。该宿主会在安装与加载时检查版本要求；不要用版本豁免代替更新插件。插件依赖宿主的插件槽位、持久化调度与本地文件写入。
- Node.js：`engines.node` 为 `>=24.21.0 <25`，以该桌面版内置的 Node `24.21.0` 为验证基线；桌面用户无需自行安装 Node。
- 一个可用的模型连接：首次出题、生成课程都要让模型跑一轮。
- 不需要 API key，也不需要在本机装 Node 或任何依赖。
- 生成课程时需要联网：素材由 Agent 搜索并抓取公开网页。

## 安装

DSH `0.2.1-rc.3` 中，打开「插件」→「添加插件」→「安装第三方插件」，在「包名或地址」填写本插件目录的绝对路径，再确认安装。若通过 `plugin_manager` 安装，使用 `install_bundle`，目标同样是这个目录的绝对路径。装完不需要填任何 API key。

更新：`git pull` 后，先备份学习数据；按 `rc.3` 的第三方插件更新提示，卸载旧插件，再从本次更新的目录重新安装。若提示重启，则重启 DSH 并刷新页面。仅修改源码或刷新页面不会替换已复制安装的旧包。从 `0.2.1-rc.2` 升级的旧插件若被拒绝，应安装本次适配包，不添加兼容性豁免。移除插件不会删除学习数据目录，本次适配也不迁移数据。

## 第一次用

1. 侧边栏点「英语教练」，填三件事：想用英语做什么、每天能挤出多久、目标档位。
2. 点「生成测评题库」，等一分钟让 Agent 出一套题；再点「开始测评（20 题）」。
3. 做完看到六个中文档位之一、一句参照、以及薄弱环节。大纲会自动生成。

## 每天怎么用

| 时机 | 做什么 |
|---|---|
| 早上（若开启自动化） | 到点自动生成草稿，药丸提示「今日课程已就绪」 |
| 有空时 | 主面板「今日」→ 开始这一课 → 逐项完成（阅读、听力、表达、测验、排序）；右栏「单词学习」兼顾到期复习和新词学习 |
| 碎片时间 | 点右下角药丸，直接答一张卡：点一个释义，答完看讲解，然后「下一个」；药丸可以拖到顺手的位置，也可点「打开主页」回到今日页 |
| 想多学几个 | 点「继续学习」，先使用到期旧词与已加入新词，再按当前词库补足本批；无合格候选时会说明原因，不暗中换源 |
| 想看看有什么词 | 「单词」→ 我的词汇 / 主题词库，搜索、筛选、翻页和查看详情 |
| 每周 | 「计划」看本周目标完成度；「个人」看进度和曲线，填写目标与兴趣 |

## 设置

设置从独立分区进入，不占主面板视图：

主面板「个人」页先显示已保存目标，就近对照当前水平估计与目标档位；长目标和全部兴趣可只读展开，不必进入编辑。点击「编辑个人目标」再修改，保存成功收起，取消放弃草稿；失败和后台轮询不覆盖草稿，离开插件内视图会提示未保存修改。下方默认显示三项学习概况，点击「查看记录」可看带日期和档位的水平曲线、完整测评记录、在学数量与诊断。

设置页保留：
- 每批学习 / 每次补充词数（3–30，默认 10）：也供课程建议出词量使用；保留旧合法设置，同日可以继续多批
- 每日自动生成：开关与生成时间（**默认关闭**）
- 朗读设置位置说明：来源、音色与语速统一在「今日」右栏的「朗读设置」选择
- 数据目录：查看或迁移

|---|---:|---:|

| 六级（含四级基础） | 5,805 | 178 |
| 雅思 | 5,040 | 143 |

跨库去重后共 7,638 个词面，其中 261 个有可练基础题（约 3.4%）。当前采用保守门槛，多义、污染及已发现语义风险条目只供浏览并说明原因；目录总量不等于可练数量。自动结构检查与非专业抽查不等于逐词专业审校。详细来源、版本、校验和与加工规则见 [数据清单](<data/manifest.json>) 和 [数据通知](<data/NOTICE.md>)。

同一规范词面跨课程、补词和词库共享既有进度，不覆盖原释义、盒子或排期；不自动合并词形、英美拼写或历史重复记录。当前词库只影响后续批次与新课程建议，选库不重做旧课。

点击单词、表达或例句旁的喇叭图标即可请求朗读；悬浮卡、学习卡、词库、阅读与听力共用同一来源。来源、音色与语速统一在「今日」右栏「单词学习」下方的「朗读设置」卡片调整，课程与词条内不重复放设置。每个来源分别记住自己的音色，共用 0.5 / 1.0 / 1.5 / 2.0 四档相对语速；不同音色的实际词速可能不同。

新用户默认推荐 **Kokoro**，精选 Heart（默认，`af_heart`）、Michael（`am_michael`）、Emma（`bf_emma`）、George（`bm_george`）。明确准备资源后，点击「试听音色」或短词旁的喇叭即可由 DSH 主机 CPU 生成并播放，准备后可离线换声。未准备时只提示，不下载、不发声，也不改用系统语音。远程网页的朗读文本会交给 DSH 主机，不是始终留在浏览器设备。阅读正文与听力文稿也支持 Kokoro 句段播放、暂停／继续、拖动和从头播放。当前 Kokoro 单次英文上限为 400 字符及 510 音素，超过会明确拒绝，不截断；文章长句会按保守小段生成，数字密集时进一步缩短，分句处的韵律可能变化。普通旧句段及书签保持兼容，确需新拆分的长句会使该篇旧坐标失效并提示。

需要立即试听时，可手动选择「系统语音」，再选择当前网页设备实际提供的本地英语 **Shelley / Reed / Sandy** 家族；不同英语口音分别列出并标明语言标签。其它声音、联网声音或没有明确本地属性的声音不列出，缺声时不会自动安装或拿任意英语声音补齐。旧系统音色仍合格时保留；暂时缺失或已移除时保留原标识并要求重选，绝不静默回退。选择、保存、重新进入页面或声库重新出现均不自动试听。

阅读与听力按空白行分段，每段译文独立展开或收起，不触发播放、作答或完成。后续新课会要求生成与英文段落一一对应的中文辅助译文；旧课没有译文时显示「暂无译文」，不会自动联网补译或重做课程。译文只供学习参考，朗读仍只使用原英文。

当前轮在同一客户端会话内由今日、单词页与悬浮层共享，导航离开后再返回仍保留题号、答案反馈和本轮统计；完成后需显式点击「继续学习」才建立新批次。刷新或重开应用不保留这一临时轮次，但已保存的作答和复习排期不受影响。

文章进度以句段定位，不是精确秒数；恢复失败或重开时可能少量重读当前句。切换来源、音色和语速保留文本位置与播放／暂停意图；未准备或失效来源会停止并提示，须手动恢复，不自动代读。单词插播会暂停文章，结束后不会自动续文。真实目标宿主音质、恢复稳定性和窄面板布局尚需验收，自动测试不证明这些体验。

### 显式准备 Kokoro 资源

「今日」右栏的「Kokoro 资源准备」是独立入口；无需先选择音色或生成课程。打开页面、读取状态或点击未准备的朗读不会代替准备操作下载模型。点击「准备 Kokoro」才从固定官方 revision 下载 q8 模型、词元配置和 Heart / Michael / Emma / George 四声，共 **94,453,730 字节（约 94.5 MB）**；该数字不含另行随插件安装的运行时代码，模型不默认捆绑。界面显示实际传输、校验及当前资源占用，可取消；断网、空间不足或校验失败后只能手动重试，不自动换源或联网代读。

资源保存在 **`$DSH_HOME/english-coach/speech/`**（未设置时为 `~/.dsh/english-coach/speech/`），不在课程、复习或书签目录。完整资源通过固定 SHA-256 校验后原子发布；重启后重新校验并离线复用，不读取开发者缓存。取消只清理本次归属明确的准备目录；中断残留在下次明确准备时校验归属并有界回收，不清理未知文件或链接。已有资源损坏时只报告，不偷偷重下；点击「修复 Kokoro 资源」后还需确认固定目标、下载量、临时磁盘与共享主机影响。修复完整重新下载同一固定版本，兼容旧集合在新集合全部校验前仍可朗读，失败或取消保留旧集合。成功后原子切换安装代际、释放旧运行时并使旧任务与音频句柄失效；完成仍保持静默。修复需额外约 94.5 MB 可用空间，双代资源预算约 189 MB，不含插件运行时与临时音频。状态显示实际资源字节；归属不明或超限残留只报告、不清理、不继续增长。当前只提供 revision `1939ad2a8e416c0acfeecc08a694d14ef25f2231`；「检查资源版本」仅核对包内固定清单，不联网，也不暗示存在更新的上游版本。

**资源准备完成仍保持静默。** 请重新点击「试听音色」或喇叭，界面会依次显示排队、加载／生成与真实播放状态；不会自动播放先前失败的内容。浏览器若要求新的播放手势，会保留当前生成音频并显示「播放生成音频」，再点即可播放，不会为此重新生成。停止、换声、隐藏或离开入口会取消本页面任务，迟到音频不会突然播放。

CPU WASM 运行时、英文词典和两套必要 G2P 小图随普通插件包提供，当前完整插件包约 **14.5 MB 压缩 / 42.4 MB 解包**，与首次准备的约 94.5 MB 模型和四声下载分别计算。无需 Python、Docker、显卡、全局依赖或开发者目录；运行时按需加载，空闲约 30 秒回收工作进程，模型仍在磁盘。生成 WAV 不写入永久录音库、不跨重启留存：单条最多 16 MiB、单页面临时复用最多 16 MiB、全主机最多 64 MiB 且最多 64 项，120 秒失效。主机仅一路合成，最多 16 个待处理页面，每页只保留最新前台任务及至多一个下一句段预取；当前音频领取后才预取，不预生成整篇。已排队的前台请求优先于预取，暂停、跳播、插播或更改朗读配置会取消旧预取。其它网页不抢断正在生成的前台小段；该小段结束后按网页轮转，连续点词只更新自己等待位置上的最新内容，不插队或挤掉另一网页。任务状态、错误与音频按已认证宿主连接和随机页面身份隔离，另一页面不能领取、取消或释放本页内容。

隐藏、关闭页面或卸载最后一个朗读入口时，会通过原有宿主传输释放本页任务和临时音频，不停止其它网页。活跃、可见的 Kokoro 声音入口（包括保留当前音频的暂停状态）每 5 秒发送轻量会话心跳，闲置学习页和系统语音不发送；主机页面租约为 15 秒，每秒检查回收。关闭请求若因网络或桌面传输中断而丢失，主机只能在租约到期后识别并回收，不能保证即刻感知断线；后台计时器暂停或长时间失联后需手动重试。心跳不延长任务／生成音频的 120 秒绝对有效期，也不复活过期句柄。最后一个主机页面所有者释放或过期时，等待实际工作进程终止并清理临时音频；已下载模型、声音偏好和文章书签保留。

本机 macOS 候选实测推理物理内存占用约 **1 GiB**，可能占用多个 CPU 核心，首次加载和生成可能需要十余秒；这不是跨平台内存硬上限、低负担或速度保证。低内存设备可能不适合启用 Kokoro，可手动选择可用的系统语音。空闲回收会释放工作进程，但不删除已准备模型。

## 数据在哪

默认 `~/DeepSeek-English/`，全部是普通 JSON 与 Markdown，可以直接备份、拷走、用编辑器看。设置页可以改到别的目录（会先复制再切换）。

```
~/DeepSeek-English/
├── profile.json          画像
├── settings.json         自动化、音频来源、界面
├── level.json            历次水平估计（曲线）
├── syllabus.json         大纲与本阶段目标
├── progress.json         完成日期、过期草稿数
├── review/items.json     复习项与盒子状态
├── review/log.jsonl      每次复习作答
├── audio/bookmarks.json  文章身份、正文版本与文本位置
├── anchors/items.json    锚题池（冻结，含哈希）
├── anchors/responses.jsonl
├── assessments/          题库与每次测评
├── lessons/YYYY-MM-DD.json / .md
├── sources/provenance.jsonl  每份素材的出处、抓取时间、许可
└── jobs.json             生成任务与每日调度绑定
```

写入都是「先写临时文件，再 rename」，并在切换前保留上一版 `.bak`。文件被截断时读取会回退到备份并给出警告，不会崩。

## 给 Agent 的六个工具

| 工具 | 方向 | 作用 |
|---|---|---|
| `english_state` | 读 | 画像、大纲、最近档位、到期复习数、近 7 天用过的素材、今天有没有课 |
| `english_save_lesson` | 写 | 提交一课；以日期为幂等键，重复提交覆盖不追加 |
| `english_save_assessment` | 写 | 提交一套至少 20 题、难度 1–6 的四选一题库 |
| `english_add_words` | 写 | 补充词汇：加入复习队列、当天可学；与已有词重复的会被跳过 |
| `english_record` | 写 | 批量补记作答与完成状态，按项去重 |
| `english_vocabulary` | 读 / 写 | 浏览词库、保存偏好、显式补词；生成课程前获取实时词库上下文 |

新课的 `reading` / `listening` 学习项可提交 `translations: string[]`。按英文正文或文稿的非空段落顺序一对一提供中文译文：空白行分段，CRLF / CR 视为换行，段内单换行不拆段；不修改原英文。提供该字段时，数量必须与英文段落一致，每项必须是非空字符串；省略字段仍兼容旧课程调用。生成新课会要求完整译文，已有课程不自动重做。

所有工具都返回同一形状：`{ ok: true, data, warnings }` 或 `{ ok: false, code, message, field? }`。校验失败不会抛异常，Agent 能读到原因并据此修正。

## 几个刻意的取舍

- **不编造素材**。每份阅读与听力必须带可访问链接、抓取时间、许可说明，缺一项就拒绝落盘。抓不到就换源，并把换了什么写进课程备注。
- **界面上不出现任何国际分级框架的名称**。六个中文档位是自建的显示层；参照只说「大致相当于」。
- **锚题自制、冻结、只退役不修改**。它只是粗检，连续三次偏离只在曲线旁加一句话，不改分数。
- **掌握的定义是硬的**：在 1 天、7 天、30 天三个间隔各答对一次。答错就回到第一盒，掌握不成立。
- **自动化默认关闭**。开启后才建每日调度；关掉应用期间漏掉的天数只补最近一次。
- **词库不拥有个人进度**。目录、当前来源偏好和复习项分开建模；浏览分页不截断学习队列。用尽不会自动调用模型或更换词库。

## 隐私

- 插件不收集遥测，不上报学习数据。
- 学习数据只写在本机数据目录；插件另外保存数据目录指针 `~/.dsh/english-coach/root.json`，以及明确准备后的朗读资源（见上节）。设置 `DSH_HOME` 时这些插件专属文件随之定位。开启自动化时的会话与调度由 Harness 宿主管理。
- 生成课程、测评及按画像补词时，提示词和素材会交给 Harness 配置的模型服务，搜索与抓取走平台能力。静态词库补词不现场调用模型或下载词典。系统朗读只允许明确标为本地的合格声音；不使用第三方联网代读。Kokoro 的处理位置是 DSH 主机，远程网页不等于浏览器设备本地。
- 课程保存采纳的阅读正文、听力文稿及来源链接、抓取时间、许可说明；不会缓存完整来源网站。
- 想删干净：移除插件不会动数据，手动删掉数据目录即可（先备份）。

## 已知限制

- 口语与发音不做评分。
- 不做图片/视频生成；Kokoro 已支持显式准备／修复、设置试听、短词与阅读／听力句段本地播放，资源删除仍待后续接入。系统语音保留文章控制；部分设备没有允许的系统音色，不保证跨平台都具备这三家族。真实宿主的长文听感、媒体恢复与跨平台体验仍需分别验收。
- 不声称与任何外部考试分数等价。
- 首次测评与每日生成都需要模型跑一轮，会产生用量；自动化默认关闭就是为了这个。
- 一次安装 = 一个学习者；不做多账号、社交、排行榜、跨设备同步。
- 只在 macOS 上实测；Windows / Linux 未验证。
- 素材可达性随网络环境变化，抓不到时会换源，不会编造。

## 常见问题

**需要 API key 吗？**
不需要。题目和课程都用 Harness 里已经配好的模型生成。

**会消耗多少额度？**
生成一套测评题库、生成一课各要跑一整轮模型（含搜索与工具调用）；做测评本身不额外调用模型。自动化默认关闭，课程先落草稿，不点开始就不会继续。

**断签一天会怎样？**
连续天数允许间隔一天，隔天再学仍然连着；超过才算断。进度统计只认完成态。

**换电脑怎么办？**
把数据目录整个拷过去，在新机器的设置里把数据目录指到同一个位置。

**能两个人共用吗？**
不能。一次安装对应一个学习者。

**抓不到素材怎么办？**
Agent 会换源并把换了什么写进课程备注；连续失败可以在面板点「重新生成」。

**界面能切成英文吗？**
不能，这是刻意的：界面固定中文，英文只出现在材料里。

## 卸载

插件管理里移除本 bundle 即可。数据目录不会被动，留着下次还能用；想清干净就手动删掉 `~/DeepSeek-English/`。

## 开发

```bash
npm run test:core
npm run test:ui
npm test
npm run check:package
```

UI 测试需要开发环境已提供 React 18.3 / React DOM 18.3 / jsdom 29，可通过 `NODE_PATH` 指向已有环境；插件本身不分发这些开发依赖。使用声明兼容的 Node 24.21.x。缺少 UI 测试环境会明确失败，不静默跳过。

`check:package` 需要开发机提供 npm 和 tar；它使用 `npm pack --ignore-scripts --offline` 生成真实压缩包，检查发布文件、许可证、入口及模块导入，并针对解包后的代码运行全部领域、Host Adapter 与 React DOM 测试，核对词库校验和与必要许可。产物和日志保存在仓库忽略的 `.scratch/package-check/`，不安装插件、不激活 Host、不访问真实学习数据。也可直接运行 `node scripts/check-package.mjs`。

兼容性声明以本机已知环境为边界：2026-10-26 核对桌面版与内置 DSH 均为 `0.2.1-rc.3`，内置 Node 为 `24.21.0`。已核对工具注册、会话／调度、HTTP 路由和客户端槽位契约；macOS 主面板通过宿主的 `--dsh-frame-top-clearance` 避让顶部窗口控件。兼容回归与完整自动测试覆盖隔离状态，真实打包检查仍使用 pack → 解包 → 全量测试；这些不代表通过真实 Profile 的安装、冷启动、卸载、回滚或宿主试听，亦不代表商城审核通过。历史版本的验证不扩展本包兼容范围，其他 DSH 版本及跨平台矩阵尚未验证。

领域与状态全部在 `core/`，是一层纯 Node 模块：给定数据目录与一条命令，返回结果并落盘。Host 做平台接线（工具、路由、调度），Client 做界面和共享语音。领域测试通过公开 execute 命令；UI 测试挂载真实 React DOM，仅在语音、宿主通信等外部依赖使用可控 Adapter。真实声音与宿主行为需单独验收。
